# Admin app: Fortune Cookie messages

VTEX Admin app to manage the messages of the [Fortune Cookie sample](https://github.com/CarlosDev88/vtex-react-app-fortune-cookie).

- Table of messages with a header and actions.
- Modal to create a message and confirmation modal to delete one.
- Data hooks (`useCreatePhrase` and others) that call the [Fortune Cookie service](https://github.com/CarlosDev88/service-vtex-fortune-cookie).
- Builders: `admin 0.x`, `react 3.x`, `messages 1.x`. UI built with `vtex.styleguide`.

```bash
vtex link
```

**Stack:** TypeScript, React, VTEX IO Admin.
